# Rhea 웹사이트

줄기세포용 원심분리기 **Rhea** 제품 소개 사이트입니다. 빌드 도구 없는 순수 HTML/CSS/JS로 만들어져 있어서, 파일을 열고 바로 편집하면 됩니다.

## 내 컴퓨터에서 미리보기

방법 1 — 그냥 열기 (가장 간단):
- `index.html` 파일을 더블클릭하면 기본 브라우저에서 열립니다.

방법 2 — 로컬 서버로 열기 (폼 동작 등을 더 정확히 보고 싶을 때):
```
cd rhea-website
python3 -m http.server 8934
```
그다음 브라우저에서 `http://localhost:8934` 접속. 종료하려면 터미널에서 `Ctrl+C`.

## 폴더 구조

```
index.html        모든 페이지 내용 (섹션별로 주석 있음)
css/styles.css     디자인(색상, 글꼴, 레이아웃)
js/main.js         모바일 메뉴, 스크롤 효과, 문의 폼 동작
assets/svg/        아이콘/파비콘
PRODUCT.md         제품·타겟 고객 정보 (impeccable 스킬이 참고)
DESIGN.md          디자인 시스템 기록 (자동 생성됨)
```

## 실제 자료가 도착하면 꼭 교체해야 할 항목 (PLACEHOLDER)

`index.html`에 `<!-- PLACEHOLDER: ... -->` 주석으로 표시해 두었습니다. `Cmd+F`(또는 `Ctrl+F`)로 "PLACEHOLDER"를 검색하면 전부 찾을 수 있습니다. 요약하면:

1. **로고** — 헤더/푸터의 원형 아이콘 워드마크를 실제 로고로 교체
2. **포지셔닝 문구** — 히어로 섹션의 헤드라인/서브헤드 (현재는 안전한 일반 문구)
3. **사양표(사양 섹션)** — "사양 확정 예정"이라고 표시된 9개 값을 실제 수치로 교체
4. **인증 섹션** — 실제 인증서가 오면 목록/배지로 교체 (허위 인증 표시 방지를 위해 지금은 비워둠)
5. **워크플로 섹션** — 고객사가 실제 워크플로 자료를 주면 그 내용으로 교체
6. **연락처(이메일)** — 문의 섹션과 푸터의 이메일/회사 정보
7. **문의 폼 연동** — 지금은 화면 동작만 있고 실제 전송 기능이 없습니다. [Formspree](https://formspree.io) 같은 무료 서비스에 가입해 `<form>` 태그의 `action` 속성만 추가하면 가장 쉽게 연결됩니다. (원하시면 다음에 제가 연결해 드릴 수 있어요.)
8. **브랜드 컬러/폰트** — 지금은 임시로 청록색(teal) 계열을 사용 중입니다. 실제 브랜드 색상이 오면 `css/styles.css` 맨 위 `:root { ... }` 안의 색상 값만 바꾸면 사이트 전체에 반영됩니다.

## 참고

- 사이트는 모바일부터 큰 데스크톱 화면까지 반응형으로 만들어졌고, Playwright로 실제 화면을 확인해 접근성(명도 대비, 포커스 표시 등)과 버그를 점검했습니다.
- 다크 모드(기기 설정이 어두운 테마일 때)도 지원합니다.
